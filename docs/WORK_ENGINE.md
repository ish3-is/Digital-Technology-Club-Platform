# محرك العمل — المرحلة الثانية

## النموذج المشترك
work_items يحمل الهوية والسياق والفصل والعنوان والوصف والأولوية والمواعيد والإصدار. التفاصيل في جداول tasks وrequests وmeetings وdecisions. التعليقات والتعيينات والمرفقات والأحداث ترتبط بالسجل الأب بواسطة FK. نوع السجل غير قابل للتغيير عبر API.

المهمة لها مسؤول رئيسي واحد ومشاركون ومراجع مختلف عن المسؤول. الطلب يحدد لجنة طالبة وأخرى مستلمة؛ مسؤول التنفيذ يُعيّن عند الاستلام، والمراجع من الجهة الطالبة. الاجتماع يقبل عدة مدعوين وردودًا مستقلة. القرار ينشأ داخل اجتماع ويحفظ صاحب القرار وتاريخه. task_sources يحفظ مصدر المهمة: طلب أو قرار، بقيد يمنع المصدر المزدوج. إكمال المهمة لا يغلق الطلب؛ يلزم اعتماد مستقل.

## الحالات
- المهمة: not_started → in_progress → review. الاعتماد ينقلها إلى completed، وطلب التعديل أو الرفض يعيدها إلى in_progress. الإلغاء وإعادة الفتح لهما قواعد مستقلة.
- الطلب: new → received → in_progress → review → completed، أو رفض/إلغاء. الاستلام والتنفيذ في نطاق الجهة المستلمة، والاعتماد في نطاق الجهة الطالبة.
- الاجتماع: scheduled → held أو cancelled. القرار: recorded → revoked.
- متأخرة حالة عرض محسوبة: الموعد قبل الآن والحالة غير مكتملة أو ملغاة أو مرفوضة. لا توجد قيمة overdue مخزنة. التقدم ٠–٩٩ يدوي، و١٠٠ فقط بعد اعتماد الإكمال.

## الاتساق والتزامن
كل تغيير يدخل معاملة تقفل صف الفصل أولًا، ثم تقرأ العنصر من جديد. ذلك يمنع إدخال دورة اعتماديات من طلبين متزامنين داخل الفصل. الربط بين فصلين ممنوع. الانتقالات والاعتماد وتعديل التفاصيل تتطلب version وتعيد 409 عند تضارب نسخة المستخدم. قيد فريد يمنع أكثر من اعتماد pending. قرار الاعتماد يستهلك الحالة المعلقة مرة واحدة.

الإكمال يعيد فحص الموانع داخل المعاملة؛ المانع الملغى لا يعد مكتملًا. التجاوز يحتاج task.override_dependency وسببًا، وكون الفاعل المراجع المحدد، مع سجل تدقيق مستقل. قفل الفصل يبسط صحة هذه النسخة لكنه يحد معدل الكتابة المتوازية؛ يمكن تحسينه بعد قياس الحمل مع إبقاء اختبارات السباق.

## الوصول
accessWhere يترجم نطاق القراءة إلى شرط SQL مشترك للقوائم والتفاصيل والبحث والوارد. التعيين في المهمة لا يمنح وصولًا خارج نطاق الدور. تعيين الفصل لا يمتد لفصل آخر. الحساب المعطل والتعيين المنتهي أو الملغى أو المرتبط بفصل مغلق لا يمنح وصولًا للعمل. الفصل المغلق يمنع الكتابة حتى للمدير؛ صاحب تعيين عام مستقل يمكنه قراءة التاريخ.

الطلب يُقرأ في نطاق أي من لجنتيه، بينما الاستلام والتنفيذ والاعتماد لها صلاحيات مستقلة. البحث حرفي في العناوين ويعيد أول ٣٠ نتيجة مصرحًا بها. لا يظهر عنوان مانع أو مهمة مرتبطة لا يمكن للمستخدم فتحها؛ تعرض حالة توقف عامة عند وجود مانع محجوب.

## الوارد والتنبيهات
الوارد مشتق من الحالة الحالية: مهمة للمسؤول أو المشارك، اعتماد للمراجع المحدد، طلب جديد للجهة المستلمة، طلب قيد التنفيذ لمسؤوله، دعوة دون رد، وإشارة دون تأكيد اطلاع. لا يُنسخ جدول التنبيهات. كل إشارة طلب اطلاع صريح، ولا يمكن ذكر من لا يستطيع فتح العنصر.

الترتيب: عاجل للأولوية العاجلة أو الموعد المتجاوز؛ اليوم وفق Asia/Riyadh؛ هذا الأسبوع للأيام السبعة التالية؛ لاحقًا للباقي أو غياب الموعد. التعادل يُكسر بالموعد ثم الإنشاء ثم المعرّف. تعرض البطاقة سبب التصنيف. عناصر الفصول غير النشطة لا تطلب إجراءات.

التنبيهات داخل معاملة الحدث، دون polling. عامل npm run work:due يفحص اقتراب الموعد حسب WORK_DUE_SOON_HOURS (٢٤ افتراضيًا، ١–١٦٨). مفتاح العمل والمستخدم والموعد يمنع التكرار. العامل قابل للربط بمجدول الاستضافة؛ لم تُنشأ خدمة جدولة خارجية. مع PGlite يجب إيقاف الخادم قبل العامل لأن البيانات تُفتح في عملية واحدة.

## الملفات
المرفق يرث إذن العنصر الأب عند كل تنزيل. لا روابط عامة أو رفع تحت public. StorageProvider له تنفيذ علائقي خاص عبر bytea يحفظ المحتوى والبيانات الوصفية والربط والأثر في معاملة. التنزيل attachment مع nosniff وno-store وCSP sandbox.

المسموح PNG وJPEG بتوقيع وامتداد مطابقين، ونص UTF-8 دون null bytes؛ حد ٥ MiB و٢٠ مرفقًا للعنصر. قراءة HTTP محدودة أثناء البث قبل تحليل النموذج. فحص التوقيع ليس فحص برمجيات خبيثة؛ ماسح الملفات ومخزن كائنات خارجي وتوسيع الأنواع مؤجلة. لا PDF أو Office أو SVG أو HTML أو ملفات تنفيذية في هذه النسخة.

## الواجهات
عملي أولًا، ثم كل المهام والطلبات والاجتماعات وسجل القرارات. التفاصيل في Drawer وعلى الجوال شاشة كاملة مع تركيز محصور. اللوحة تعكس حالة الخادم: تغيير الحالة من البطاقة ينقلها للعمود الصحيح؛ الإكمال عبر المراجعة فقط، وليس سحبًا يتجاوز القيود. الإنشاء من لجنة أو طلب أو قرار يحمل السياق تلقائيًا. Ctrl+K يجمع البحث والتنقل والإنشاء المصرح. حقول المواعيد جاهزة للتقويم؛ واجهة Gantt مؤجلة.

## امتداد الفعاليات — المرحلة الثالثة

work_items يدعم الآن kind=event مع تفاصيل events، وevent_id اختياريًا على المهمة والطلب والاجتماع والقرار. إنشاء الفعالية وانتقالاتها من Event Engine؛ مسار work العام يرفض تغييرها لتجنب تجاوز شروط المراحل. إنشاء المهام بالقالب يستخدم نفس خدمات العمل داخل معاملة الفعالية. التفاصيل في EVENT_ENGINE.md.
