# نظام التصميم

RTL-native باستخدام inline/block وgrid عربي الترتيب. خط Noto Sans Arabic مستضاف محليًا. أسطح محايدة، أزرق الهوية accent، أخضر نجاح وعنبر تنبيه وأحمر خطأ. اللون ليس حامل المعنى الوحيد.

Tokens: background #f5f6f8، surface #ffffff، ink #172334، muted #657185، accent #2448eb؛ dark background #101720، surface #19232f، ink #eef3fa. المسافات 4/8/12/16/24/32/48/64؛ أحجام الخط 12/14/16/20/28/40؛ radius 10/16/24؛ ظل ناعم للأسطح المرتفعة فقط. نقاط الاستجابة 640/960/1280. CSS هو مصدر tokens التنفيذي.

الأصول: club-light.png أبيض للخلفية الداكنة، club-dark.png أسود للخلفية الفاتحة، club-primary.png الهوية الرئيسية لخلفية مناسبة للنص الأبيض، university.png شعار الجامعة. النسخ تحفظ البايتات والنسب؛ object-fit: contain. لا إعادة رسم أو توليد. مراجعة اللون النهائية مقابل الأصول المصورة موثقة عند التحقق البصري.

الأزرار: رئيسي ممتلئ، ثانوي محايد، رابط نصي. المدخل label دائم وخطأ role=alert؛ الجداول عند الحاجة فقط. حالات فارغة بوصف مفيد دون إحصائيات مختلقة. إشعارات status؛ skeleton عند تحميل المسارات؛ dialog بلوحة مفاتيح وتركيز محصور؛ قائمة أوامر Ctrl+K / Cmd+K وEscape. رابط تجاوز إلى المحتوى، focus مرئي. الجوال شريط سفلي للإجراءات اليومية وقائمة إضافية للوجهات الثانوية؛ ليس نسخ الشريط الجانبي.


## أسطح العمل في المرحلة الثانية

قائمة وKanban للحالات الفعلية، مع مرشحات اللجنة والحالة والأولوية والبحث. عملي يجمع المتأخر واليوم والأسبوع والمراجعة والمكتمل. الوارد يعرض سبب الترتيب والإجراء التالي. Drawer جانبي للتفاصيل على الحاسوب يتحول إلى شاشة كاملة على الجوال؛ لا سحب وإفلات، وتغيير الحالة إجراء صريح مع تحقق الخادم. الإنشاء من سياق اللجنة أو الاجتماع أو الطلب يحافظ على السياق. الحوار ولوحة الأوامر يستخدمان Radix لإدارة التركيز ولوحة المفاتيح. لقطات المراجعة محفوظة في test-results بعد اختبار Edge.

## غرفة عمليات الفعالية

صفحة الفعاليات تجمع الأعمال بحسب المرحلة بدل جدول إدارة فقط. الغرفة تبدأ بالعنوان والسياق ومرحلة حالية على stage rail، ثم جاهزية قابلة للفتح وتفسير الموانع. التبويبات تفصل العمل والفريق والحضور والملفات والتقرير دون ازدحام المؤشرات. على الجوال تتحول الأعمدة إلى مسار واحد، مع تمرير أفقي محلي لشريط المراحل والتبويبات، ونموذج إنشاء يملأ الشاشة. لا أرقام جاهزية أو حضور أو ميزانية خارج مصدر بيانات فعلي.
