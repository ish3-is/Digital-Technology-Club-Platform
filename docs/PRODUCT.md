# المقر الرقمي لنادي التقنية الرقمية

نظام تشغيل طلابي لجامعة الملك خالد؛ يربط الأشخاص بالأدوار والعمل بالقرارات والأدلة. العربية لغة الإصدار الأول وRTL أصل التصميم.

## نطاق التسليم
المرحلة صفر: تثبيت النموذج والقرارات. المرحلة الأولى: الهوية والجلسات والصلاحيات والتنظيم. المرحلة الثانية: مهام وطلبات واجتماعات وقرارات واعتمادات وتعليقات ومرفقات محمية وبحث ووارد فعلي. المرحلة الثالثة: فعاليات مترابطة مع العمل والفريق والتسجيل والحضور والجاهزية والمخاطر والتقرير النهائي. المالية الكاملة والنقاط والمعرفة التنفيذية ليست ضمن التسليم.

## خريطة التنقل
الرئيسية ← إجراءات الشخص وتغيراته؛ صندوق الوارد ← ما يحتاج إجراء؛ التنبيهات منفصلة من رمز الجرس؛ العمل ← عملي / كل المهام / الطلبات / الاجتماعات / سجل القرارات؛ الفعاليات؛ اللجان؛ النادي؛ الإنجازات؛ المعرفة. الإدارة تظهر لمن يملك organization.manage وملخص المشرف لصاحب report.review. الملف الشخصي وإدارة الجلسات من الحساب.

المسارات المستقبلية تعرض شرحًا صادقًا دون أزرار شكلية أو أرقام افتراضية. Ctrl+K يبحث الآن في العمل المصرح ويقدم أوامر إنشاء فعلية.

## قواعد المنتج
كل مؤشر له مصدر وطريقة حساب وتاريخ. كل اعتماد له صاحب قرار وأثر تدقيقي. لا تجاوز للاعتماديات إلا بصلاحية مستقلة وسبب مسجل. فصول مغلقة للقراءة فقط. لا بيانات شخصية أو أرقام جامعية في الأنشطة العامة. لا تسجيل ذاتي مفتوح؛ الحسابات مؤسسية ويجهزها مدير النظام.
