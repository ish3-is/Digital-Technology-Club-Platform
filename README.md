> منصة تشغيل وإدارة عربية RTL لنادي التقنية الرقمية بجامعة الملك خالد، تجمع أعمال النادي في بيئة رقمية واحدة تشمل الأعضاء، اللجان، المهام، الفعاليات، الطلبات، العمليات التخصصية، الحوكمة، التقارير، والاستنتاجات التشغيلية.

**إعداد وإشراف:** مشعل الجذمي — رئيس اللجنة الرقمية  
**المستودع:** https://github.com/ish3-is/Digital-Technology-Club-Platform

## نبذة عن المنصة

**المقر الرقمي لنادي التقنية الرقمية** هو نظام تشغيل يومي متكامل للنادي، وليس مجرد لوحة معلومات أو موقع تعريفي.

تهدف المنصة إلى توحيد دورة العمل داخل النادي من لحظة إنشاء المهمة أو الفعالية وحتى التنفيذ، المراجعة، الاعتماد، التوثيق، وقياس الأثر.

تعتمد المنصة على:

- واجهة عربية كاملة واتجاه RTL.
- صلاحيات مبنية على الأدوار والنطاقات التنظيمية.
- فصل واضح بين العرض والمراجعة والاعتماد.
- ربط الأعمال باللجان والفصول الأكاديمية والمستخدمين.
- تقارير ومؤشرات قابلة للتتبع إلى مصدر البيانات.
- سجل تدقيق للعمليات الحساسة.
- فصل بيانات التطوير والعرض التجريبي عن بيئة الإنتاج.

# التقنيات والمكتبات المستخدمة

> **مهم:** القائمة المرجعية النهائية لإصدارات جميع الحزم هي `package.json` و`package-lock.json` داخل المستودع. لا يلزم تثبيت الحزم يدويًا؛ `npm ci` يثبت الإصدارات الصحيحة تلقائيًا.

## Runtime / Application Dependencies

- **Next.js 16.3.6** — إطار التطبيق وApp Router وServer Components وRoute Handlers.
- **React 19** — بناء واجهات المستخدم.
- **React DOM** — تشغيل React داخل المتصفح.
- **Better Auth** — المصادقة والجلسات وتسجيل الدخول.
- **Drizzle ORM** — طبقة ORM والتعامل مع PostgreSQL.
- **PGlite** — PostgreSQL محلي مضمّن للتطوير والاختبارات.
- **PostgreSQL Driver (`pg`)** — الاتصال بقاعدة PostgreSQL في البيئات الخارجية والإنتاجية.
- **Zod** — التحقق من المدخلات والبيانات والإعدادات.
- **Nodemailer** — إرسال البريد الإلكتروني واستعادة كلمة المرور.
- **Radix UI Dialog** — مكونات Dialog/Modal قابلة للوصول.
- **Lucide React** — الأيقونات.

## Development / Testing Dependencies

- **TypeScript** — اللغة وفحص الأنواع.
- **tsx** — تشغيل سكربتات TypeScript مباشرة.
- **Vitest** — اختبارات Unit/Integration.
- **Playwright** — اختبارات End-to-End واختبارات المتصفح.
- **@types/node** — تعريفات TypeScript لـNode.js.
- **@types/react** — تعريفات TypeScript لـReact.
- **@types/react-dom** — تعريفات TypeScript لـReact DOM.

## تقنيات ومعايير مستخدمة داخل المشروع

- Next.js App Router.
- React Server Components وClient Components.
- REST-like Route Handlers داخل Next.js.
- Arabic RTL UI.
- RBAC + Scoped Permissions.
- Session Management.
- Rate Limiting.
- Content Security Policy (CSP).
- HSTS.
- Audit Logging.
- Append-only Audit Protection.
- PostgreSQL Migrations.
- Production Configuration Validation.

# نموذج الصلاحيات

تعتمد المنصة على **RBAC + Scoped Permissions**.

يمكن أن تكون الصلاحية مرتبطة بـ:

- النادي.
- اللجنة.
- المستخدم.
- الفصل الأكاديمي.

ومن المبادئ المعتمدة داخل النظام:

```text
evidence.view != evidence.verify
```

أي أن الاطلاع على الدليل لا يعني امتلاك صلاحية التحقق منه.

وكذلك:

```text
report.review != report.approve
```

أي أن مراجعة التقرير منفصلة عن اعتماده.

كما أن المشرف لا يحصل تلقائيًا على صلاحيات تعديل داخلية في جميع اللجان.
